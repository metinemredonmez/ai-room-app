Aşağıdaki görüntüler 3 Kasım 2026'da çalışan MVP'den alındı.

  • Şekil A: uygulamanın kendi örnek fotoğrafını ve gerçek Gemini 2.5 Flash Image sağlayıcısıyla "Modern Türk" stilinde üretilen sonucu gösteriyor. Örnek, Pexels lisanslı gerçek bir oda fotoğrafıdır; pencere, kapı ve perspektif korundu.

17Ekler

17.1 Çalıştırma talimatları (özet)

Gereksinimler:

  • Node 22 (mobil için ≥ 22.13; diğer uygulamalar Node 20.9+ ile de çalışır).
  • Python 3.12+ ve uv.
  • PostgreSQL 15+, Redis 7+.

Ayrıntılar depo kökündeki README.md ve her uygulamanın kendi README dosyasında.

# 1) Backend (port 4000)
cd apps/backend && cp .env.example .env    # DATABASE_URL + 4 sır (openssl rand -base64 48)
npm install && createdb ai_room && npx prisma migrate deploy
npm run db:seed                            # 15 stil + TOTP'li admin → data/admin-credentials.txt
npm run build && npm run start:prod

# 2) AI servisi (port 8001, INTERNAL_TOKEN = backend AI_INTERNAL_TOKEN)
cd apps/ai-service && cp .env.example .env && uv sync
uv run uvicorn app.main:app --port 8001     # IMAGE_PROVIDER=mock | gemini | replicate

# 3) İstemciler
cd apps/web    && npm install && npm run dev   # http://localhost:3000
cd apps/admin  && npm install && npm run dev   # http://localhost:3001 (TOTP: npm run admin:otp)
cd apps/mobile && npm install && npx expo start # i = iOS simülatör, w = web

# 4) Testler
cd apps/ai-service && uv run pytest          # 8 test
cd apps/backend && npm test                  # birim testleri
node scripts/smoke.mjs                       # 40 uçtan uca kontrol

Gerçek sağlayıcılar: IMAGE_PROVIDER=gemini + GEMINI_API_KEY, IMAGE_PROVIDER=replicate + REPLICATE_API_TOKEN, ANTHROPIC_API_KEY (Claude). Üretimde mock sağlayıcıyla açılış reddedilir. Docker: depoda bir docker compose dosyası var; bu makinede Docker olmadığı için çalıştırılarak denenmedi.

ASOUygulama mağazası optimizasyonu.
MFA / TOTPÇok faktörlü kimlik doğrulama / zaman tabanlı tek kullanımlık kod (RFC 6238).
Sanal döşemeVirtual staging: boş mekân fotoğrafını yapay zekâ ile mobilyalı göstermek.
RoomPlan / LiDARApple'ın oda tarama API'si ve derinlik sensörü; gerçek ölçü sağlar.
Yapı korumaYeniden tasarımda pencere, kapı, duvar ve perspektifin aynı kalması.
AffiliateYönlendirilen satıştan komisyon alınan ortaklık modeli.
YBBOYıllık bileşik büyüme oranı (CAGR).
ARPPU / LTVÖdeme yapan kullanıcı başına gelir / müşteri yaşam boyu değeri.

P0 / P1Red-team kataloğu öncelikleri: P0 ilk güvenli yayın öncesi temel bariyer, P1 ilk derinlik dalgası.
