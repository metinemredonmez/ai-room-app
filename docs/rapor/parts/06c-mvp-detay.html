Ana akış: POST /designs

  1. Şema doğrulaması (zod, strict); kullanıcı ve IP hız limitleri.
  2. PRO araç veya stil kontrolü (pro_required, 402); referans görsel zorunluluğu.
  3. Girdi ve referans görselin sahiplik kontrolü (yoksa 404).
  4. PENDING kaydı açılır. Hak SELECT … FOR UPDATE ile düşülür: önce günlük ücretsiz, sonra kredi. Yetmezse 402.
  5. Semafor sonrası AI servisi çağrılır. Çıktı yeniden kodlanır; ücretsiz planda AI etiketi eklenir; RESULT görseller kaydedilir.
  6. SUCCEEDED → Design DTO, imzalı URL'lerle. Hata olursa FAILED olur ve hak iade edilir.

Kabul kriterleri

  • ✓ Misafir → katalog → örnek → 2 varyant üretimi → kota 3→1 (smoke)
  • ✓ Kota aşımında 402; PRO stilde pro_required (smoke)
  • ✓ Başka kullanıcının tasarımı ve görseli 404 (smoke)
  • ✓ Refresh yeniden kullanımında aile iptali; admin API'de uygulama token'ı 401 (smoke)
  • ✓ Admin MFA, kod tekrarı reddi, öne çıkarma ve denetim kaydı (smoke)
  • ✓ Typecheck, lint ve build temiz
  • ◐ Ban sonrası anında iptal, misafir yükseltmede oturum yenileme
  • ✓ Şifre sıfırlama ve e-posta doğrulama: tek kullanımlık, amaca ve e-postaya bağlı token; Host başlığına güvenmeyen bağlantı; sıfırlamada tüm oturumların iptali (AUT-03, MAIL-01, SES-04 — smoke)
  • ○ Asenkron kuyruk, S3/R2, IAP webhook'ları, admin oturum iptal ucu, RLS

9.2 AI servisi — Python FastAPI (apps/ai-service)

Amaç ve uçlar

Model ve sağlayıcı bağımlılığını üründen ayırır. Görselleri ve modelden gelen çıktıyı güvenilmez sayıp her seferinde doğrular.

  • POST /internal/v1/generate: 10 araç şablonu, 1–4 varyant, referans stil (Claude tarifi).
  • POST /internal/v1/analyze: JSON şemalı ürün ve tadilat listesi, Pillow paleti.
  • POST /internal/v1/chat: katalog kimlikleriyle süzülen öneriler.
  • GET /internal/v1/health: sağlayıcı ve sohbet durumu. GET /healthz: canlılık.
  • Sağlayıcılar: mock (çevrimdışı), gemini (Gemini 2.5 Flash Image), replicate (FLUX.1 Kontext Pro). Claude için ANTHROPIC_API_KEY.

Kabul kriterleri

  • ✓ Token'sız ve yanlış token 401; doğru token 200 (pytest)
  • ✓ 2 varyant üretimi; prompt'ta stil ve oda var (pytest)
  • ✓ Kullanıcı metninde <, {, satır sonu temizleniyor (pytest)
  • ✓ Görsel olmayan girdi ve bilinmeyen alan reddediliyor (pytest)
  • ✓ Referans aracı referans görsel istiyor; analiz demo yanıtında palet ve min ≤ maks (pytest)
  • ✓ Sohbet önerileri katalog dışı kimlikleri düşürüyor; güvensiz ayarla açılış reddediliyor (pytest)
  • ✓ Gerçek Gemini çağrısı ~9 sn'de sonuç döndürdü (tek örnek)
  • ○ Maske ile düzenleme, derinlik/kenar koşullama, yüz maskeleme, NSFW moderasyonu, kendi GPU modeli
